# MediOS Releases

Public download artifacts for **MediOS** (clinic app + lobby display Windows installers).

- The code repository is private; only built installers are mirrored here so download links and the in-app updater work without a GitHub login.
- Each `vX.Y.Z` release is published automatically by the release workflow in the private repo.
- Get the latest installer from the [latest release](../../releases/latest).
